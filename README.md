# Wooden Factory

Статичний експорт сайту [Wooden Factory](https://wooden-factory.webflow.io/) з Webflow.
Джерело: `wooden-factory.webflow.zip`, дата публікації в експорті: 28 жовтня 2026 року.

## Файли

- `index.html` — головна сторінка.
- `about-us.html`, `contacts.html`, `product-categories.html` — основні сторінки.
- `detail_*.html` — експортовані шаблони CMS та товарів.
- `checkout.html`, `paypal-checkout.html`, `order-confirmation.html` — шаблони оформлення замовлення.
- `401.html` — шаблон сторінки захисту паролем.
- `css/`, `js/`, `images/`, `fonts/` — ресурси сайту.

Файли з архіву збережено без змін. Архів залишається локально та виключений із Git.

## Перегляд і розміщення

Збірка та встановлення залежностей не потрібні. Запустіть будь-який локальний HTTP-сервер
у корені проєкту, наприклад `python -m http.server 8000`, якщо Python встановлено,
та відкрийте `http://localhost:8000/`.

Для GitHub Pages виберіть у Settings → Pages публікацію з гілки `main`, каталог `/(root)`.
Файл `.nojekyll` вимикає обробку Jekyll. Посилання на основні сторінки та ресурси відносні.
GitHub Pages не налаштовується автоматично самим завантаженням цього репозиторію.

## Межі експорту

- У CMS-блоках є порожні поля та `No items found.`. Записи CMS не перенесені цим архівом.
- Для контактної форми та підписки потрібен робочий обробник на новому хостингу.
- Кошик, оплата й оформлення замовлення залежать від Webflow Ecommerce.
  Самі HTML-шаблони не створюють робочий магазин.
- `401.html` не забезпечує захист паролем на статичному хостингу.
- Google Fonts, jQuery, GSAP, Google Maps та власний `site.js` завантажуються із зовнішніх серверів.
  `site.js` посилається на зафіксований коміт у `Yevhen-2012/webflow-assets` через jsDelivr.
- У вихідних файлах залишилися посилання-заглушки `#` і службові посилання Webflow.

Публікація цього експорту не дорівнює перенесенню серверних функцій Webflow.
