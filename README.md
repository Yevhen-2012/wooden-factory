# Wooden Factory

Статичний експорт сайту [Wooden Factory](https://wooden-factory.webflow.io/) з Webflow.
Джерело: `wooden-factory.webflow.zip`, дата публікації в експорті: 28 жовтня 2026 року.

Опублікований сайт: [GitHub Pages](https://yevhen-2012.github.io/wooden-factory/).
Репозиторій: [Yevhen-2012/wooden-factory](https://github.com/Yevhen-2012/wooden-factory).

## Файли

- `index.html` — головна сторінка.
- `about-us.html`, `contacts.html`, `product-categories.html` — основні сторінки.
- `detail_*.html` — експортовані шаблони CMS та товарів.
- `checkout.html`, `paypal-checkout.html`, `order-confirmation.html` — шаблони оформлення замовлення.
- `401.html` — шаблон сторінки захисту паролем.
- `css/`, `js/`, `images/`, `fonts/` — ресурси сайту.
- `latest-project/<slug>/index.html` — 10 сторінок проєктів із CMS.
- `data/latest-projects.csv` — опубліковані записи з наданого CMS-експорту.
- `data/projects.json` — нормалізовані дані з локальними шляхами до фото.

Дизайн і ресурси з архіву збережено. Три посилання категорій на головній сторінці
змінено з домену Webflow на локальну `product-categories.html` зі збереженням параметра
`category`. Посилання попереднього завантаження головної сторінки також зроблено відносними,
щоб вони працювали в каталозі GitHub Pages. Архів залишається локально та виключений із Git.

## Перегляд і розміщення

Збірка та встановлення залежностей не потрібні. Запустіть будь-який локальний HTTP-сервер
у корені проєкту, наприклад `python -m http.server 8000`, якщо Python встановлено,
та відкрийте `http://localhost:8000/`.

Для GitHub Pages виберіть у Settings → Pages публікацію з гілки `main`, каталог `/(root)`.
Файл `.nojekyll` вимикає обробку Jekyll. Посилання на основні сторінки та ресурси відносні.
Для цього репозиторію GitHub Pages уже налаштовано: `main` → `/(root)`.

## Межі експорту

- Колекцію Latest projects перенесено з CSV: 10 записів, 46 фото в галереях
  після вилучення повторів у межах кожного проєкту та 49 унікальних файлів зображень
  разом з обкладинками. Фото зберігаються в `images/projects/`.
  Головна сторінка містить усі 10 проєктів, від новіших до старіших за датою завершення.
- Шляхи `/latest-project/<slug>/` збережено від початкового сайту.
  Назви, описи, міста й дати взято з CSV. Фіксовані значення площі, кількості меблів
  та опис матеріалу із порожнього шаблону вилучено, бо CSV їх не містить.
- Інші колекції CMS, товари та категорії ще не перенесені: їхніх даних у наданому CSV немає.
- Це статичні сторінки на GitHub Pages. Адмінпанель Webflow CMS не перенесена.
- Для контактної форми та підписки потрібен робочий обробник на новому хостингу.
- Кошик, оплата й оформлення замовлення залежать від Webflow Ecommerce.
  Самі HTML-шаблони не створюють робочий магазин.
- `401.html` не забезпечує захист паролем на статичному хостингу.
- Google Fonts, jQuery, GSAP, Google Maps та власний `site.js` завантажуються із зовнішніх серверів.
  `site.js` посилається на зафіксований коміт у `Yevhen-2012/webflow-assets` через jsDelivr.
- У вихідних файлах залишилися посилання-заглушки `#` і службові посилання Webflow.

Публікація цього експорту не дорівнює перенесенню серверних функцій Webflow.

## Оновлення проєктів

Потрібен Node.js 22 або новіший. Пакети npm не потрібні.

```powershell
node scripts/import-projects.mjs "шлях/до/нового-експорту.csv"
```

Імпортер перевіряє колонки, унікальність slug і дати; пропускає Draft/Archived записи;
завантажує нові фото; оновлює картки, сторінки, CSV та JSON. Видалені або приховані
записи прибираються зі згенерованих сторінок. HTML описів обмежено безпечними тегами.
Повтори фото в галереї видаляються зі збереженням початкового порядку.

Після імпорту перегляньте зміни, створіть коміт і завантажте його в `main`.
GitHub Pages опублікує оновлення. Файл `detail_latest-project.html` залишається шаблоном
для генерації; редагуйте його або імпортер, а не згенеровані сторінки.
